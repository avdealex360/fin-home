# Раздел «Инвестиции» — дизайн

Дата: 2026-08-06. Статус: одобрено (обсуждено в диалоге, реализация в два этапа одним заходом).

## Цель

Справочный раздел `#/invest` (ссылка из More) для новичка, начинающего инвестировать
через ИИС в Сбербанке: база знаний, живая витрина рынка (MOEX), AI-обзор.
Как и калькулятор вклада — раздел справочный: не влияет на бюджет и 50/30/20,
не требует миграций БД.

## Не входит (YAGNI)

- Учёт портфеля (какие бумаги куплены, P&L) — отдельный будущий этап.
- «Прогнозы» из внешних источников/скрейпинга — нет надёжных бесплатных источников.
- Новые таблицы БД — всё состояние в `Setting` воркспейса.

## Блок 1: база знаний

Статический curated-контент в `routes/Invest.svelte` (аккордеон-карточки по образцу FAQ):
ИИС-3 (типы А/Б закрыты для новых договоров с 2024), вычеты, классы активов,
диверсификация, типовые портфели новичка, типичные ошибки, специфика Сбера
(SBMX, SBGB, LQDT и т.п.). Без генерации на лету.

## Блок 2: рынок сегодня

- `services/moex.py` — клиент MOEX ISS (`iss.moex.com`, без ключей):
  котировки + изменение за день для тикеров watchlist. Поддержка индексов
  (IMOEX), акций (TQBR), фондов (TQTF). In-memory кэш ~10 минут.
- `GET /api/invest/market` — котировки по watchlist воркспейса.
- Watchlist: `Setting` ключ `invest.watchlist` (CSV тикеров),
  дефолт `IMOEX,SBER,SBMX,LQDT`. Редактирование на странице:
  `PUT /api/invest/watchlist`.
- MOEX недоступна → понятная деградация («данные временно недоступны»),
  страница работает.

## Блок 3: AI-обзор

- `GET /api/invest/overview`: раз в календарный день собирает промпт из данных
  MOEX (индекс, движения watchlist) → `ai/router.py` (YandexGPT→GigaChat) →
  кэш в `Setting` (`invest.overview`, `invest.overview_date`).
- Промпт: объяснительный тон для новичка, без «купи X».
- Постоянный дисклеймер: «Не является индивидуальной инвестиционной рекомендацией».
- Ключи AI не настроены → блок скрыт, подсказка про «Интеграции».

## Ошибки и тесты

- moex.py — httpx.MockTransport: парсинг ответа ISS, ошибка сети → MoexError.
- API: watchlist дефолт/обновление, скоупинг по workspace, кэш обзора в пределах дня.
- Фронт: сборка; ручная проверка UI.
