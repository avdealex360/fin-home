# Кошелёк USDC (ERC-20): баланс и уведомление «зарплата пришла»

Приложение раз в 5 минут спрашивает у Etherscan баланс USDC на одном
Ethereum-адресе (например, кошелёк Trust Wallet, на который приходит зарплата) и:

- показывает баланс на Главной — тап по большому числу переворачивает его
  с рублёвого баланса на баланс кошелька и обратно;
- когда баланс поднимается выше заданного порога, **один раз за календарный
  месяц** пишет в Telegram: похоже, зарплата пришла.

На бюджет и 50/30/20 фича не влияет: операций она не создаёт. Пришедшую
зарплату записывайте как обычный «Доход» — руками или сообщением боту.

## 1. Что понадобится

| Что | Где взять |
|-----|-----------|
| Адрес кошелька | Trust Wallet → выбрать USDC → «Получить»; сеть **Ethereum (ERC-20)**, адрес вида `0x…` (40 hex-символов) |
| API-ключ Etherscan | [etherscan.io](https://etherscan.io) → регистрация → **Profile → API Keys → Add** |
| Работающий Telegram-бот | [telegram-bot-setup.md](telegram-bot-setup.md) — нужен только для уведомления |

Бесплатного тарифа Etherscan хватает с запасом: 5 запросов в секунду и
100 000 в сутки против наших ~288 в сутки на один кошелёк.

## 2. Настройка в приложении

1. «Ещё» → **«Телеграм-бот, AI и кошелёк»** (раздел виден только админу).
2. Блок **«Кошелёк USDC (ERC-20)»**:
   - **Адрес кошелька** — `0x…` (Ethereum mainnet);
   - **Etherscan API-ключ**;
   - **Порог, USDC** — сумма, выше которой это уже похоже на зарплату
     (ставьте чуть ниже ожидаемой суммы, например 900 при зарплате 1000);
   - **Кому писать** — конкретный участник или все, у кого привязан Telegram.
3. **«Сохранить кошелёк»** → **«Проверить сейчас»**: под кнопками должен
   появиться баланс и время обновления.
4. Откройте Главную и нажмите на большое число — карточка перевернётся
   на баланс кошелька.

Уведомления писать некому, пока ни у одного участника не заполнен Telegram ID
(«Ещё» → участники → карандаш). Приложение об этом предупредит прямо в блоке.

## 3. Как работает уведомление

- Опрос — каждые 5 минут (`crypto_wallet.POLL_INTERVAL_SECONDS`), первый
  через 20 секунд после старта приложения.
- Условие: `баланс ≥ порог` **и** в этом календарном месяце ещё не писали.
  Факт отправки хранится в настройке `wallet.alert_month` (`YYYY-MM`), поэтому
  повторных сообщений каждые 5 минут не будет.
- В сообщении: баланс, прирост с прошлой проверки (если он был), порог
  и напоминание записать доход.
- Порог `0` = уведомления выключены, баланс всё равно показывается.
- Кнопка «Проверить сейчас» и переворот баланса тоже могут отправить
  уведомление — правило «раз в месяц» одно на всех.

## 4. Где что лежит

| Ключ настройки | Область | Смысл |
|----------------|---------|-------|
| `wallet_address` | workspace | адрес кошелька |
| `wallet_threshold` | workspace | порог в USDC |
| `wallet_notify_user_id` | workspace | кому писать (пусто = всем привязанным) |
| `wallet.balance`, `wallet.checked_at`, `wallet.error`, `wallet.alert_month` | workspace | кэш и состояние |
| `secret.etherscan_api_key` | install-wide | ключ Etherscan (как токен бота) |

Ключ хранится в таблице `settings` с префиксом `secret.` — значит, он не попадает
в экспорт данных и наружу отдаётся только флагом «задан», как остальные секреты.
Полный адрес API тоже не отдаёт: в интерфейс уходит маска `0x5564…3148`.

Код: `backend/app/services/crypto_wallet.py` (опрос, порог, уведомление),
`backend/app/api/wallet.py` (`GET/POST /api/wallet`, `POST /api/wallet/refresh`),
`frontend/src/lib/wallet.ts` + переворот в `frontend/src/routes/Dashboard.svelte`.
Миграций нет — всё в `Setting`.

## 5. Отладка

- **`Invalid API Key`** — ключ не тот или ещё не активирован; проверьте
  Profile → API Keys на etherscan.io.
- **`Max rate limit reached`** — редко, при частых нажатиях «Проверить сейчас».
  Прошлый баланс при ошибке не стирается, ошибка видна в блоке настроек и
  на обратной стороне карточки.
- **Баланс есть, уведомления нет** — порог `0`, ни у кого не привязан Telegram ID,
  не задан токен бота, или за этот месяц уже писали (см. подпись «уведомление
  за YYYY-MM уже отправлено»).
- **Пришло на другую сеть** (BEP-20, Polygon, Arbitrum) — этот кошелёк смотрит
  только Ethereum mainnet, баланс не изменится.
- Логи: `make prod-logs`, искать `crypto_wallet`.
- Отключить фичу: кнопка **«Отключить»** — стирает адрес, опрос прекращается,
  переворот на Главной пропадает.
